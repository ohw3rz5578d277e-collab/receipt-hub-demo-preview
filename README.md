# Receipt Hub — Public Sample Demo (v42)

This public repository deliberately contains **only** a browser-based demo (`index.html`).
No backend, actual receipt images, customer data, secrets, credentials, or accounting exports.

- All sample changes are in each browser's localStorage; devices do **not** synchronize.
- Do **not** enter real receipts, personal information, or accounting data.
- This does **not** connect to Yayoi, Google Drive, or actual OCR.
- This is not a production accounting or archival service.

To stop public access, disable Pages in repository Settings > Pages.
